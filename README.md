# Asansör Düğmesine Hitaben Açık Mektup Protokolü

Bu depo, asansör düğmesiyle **devletlerarası düzeyde** iletişim kurmak için yazılmıştır.

Yıllardır düğmeye basıyoruz. Düğme cevap vermiyor. Bilim bunu çözemedi. Diplomasi çözecek.

## Ne yapar?

1. Düğmeye resmi hitapla mektup yazar.
2. Üç saniye diplomatik sessizlik uygular.
3. Yüzde yetmiş beş ihtimalle düğme "tamam" der.
4. Yüzde yirmi beş ihtimalle düğme mektubu arşive atar. Tıpkı hayat gibi.

## Kurulum

```bash
python3 mektup.py 7
```

Argüman vermezseniz program size kat sorar. Asansör yoksa da çalışır. Bu bir özelliktir.

## Bilimsel dayanak

- Düğmeler ihmal edilmekten yorulur.
- Açık mektup, kapalı asansörden daha etkilidir.
- Merdiven her zaman oradadır ama merdiven mektup okumaz.

## Sık sorulan sorular

**Düğme gerçekten okuyor mu?**  
Hayır. Ama biz yazıyoruz. Medeniyet böyle ilerler.

**Neden Türkçe?**

**Patates var mı?**
